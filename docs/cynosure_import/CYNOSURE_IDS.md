# CYNOSURE_IDS.md

# Ash Cache — Cynosure Canonical ID Registry

## Purpose

Canonical identifier registry for every Cynosure room, trigger, interaction, scene, environmental sequence, world object, look target, audio event, light group, streaming group, custom asset, objective, debug teleport, and logical subsystem.

Once defined here, do not invent a second name for the same concept.

## Prefixes

| Prefix | Purpose |
|---|---|
| `CYN_ROOM_` | Room/area |
| `CYN_TRG_` | Trigger volume |
| `CYN_INT_` | Player interaction |
| `CYN_SCN_` | Narrative/gameplay scene |
| `CYN_SEQ_` | Environmental sequence |
| `CYN_OBJ_` | Physical world object |
| `CYN_LOOK_` | Look target |
| `CYN_SFX_` | Audio event |
| `CYN_AMB_` | Ambient layer |
| `CYN_LGT_` | Lighting group |
| `CYN_STREAM_` | Streaming group |
| `CYN_ASSET_` | Custom asset |
| `CYN_DEV_` | Device/controller |
| `CYN_EVT_` | Logical event |
| `CYN_QOBJ_` | Journal objective |
| `CYN_TP_` | Debug teleport |
| `CYN_DBG_` | Debug helper |
| `CYN_AI_` | AI group |
| `CYN_MARKER_` | Quest/map marker |
| `CYN_LOC_` | Localization group |
| `CYN_CONN_` | Logical room/world connection |
| `CYN_CLEARANCE_` | Non-playable machine/animation safety volume |
| `CYN_VOLUME_` | Logical/effect/gameplay volume that is not a quest trigger |

## Naming rule

Object, interaction, scene, sound, look target, and asset IDs are separate layers.

Example:
```text
CYN_OBJ_READER_01
CYN_INT_BIOMETRIC_READER
CYN_SCN_BIOMETRIC_MATCH
CYN_SFX_BIOMETRIC_SCAN
CYN_LOOK_BIOMETRIC_SCREEN
CYN_ASSET_FIA_READER
```

Avoid aliases such as `CYN_TRIGGER_*`, `CYN_MODEL_*`, or `ASH_TRG_*`.

## Claude rule

Before creating any new ID:

1. search this file;
2. reuse an existing concept if present;
3. if genuinely new, choose the correct prefix;
4. add it here first;
5. only then use it in code/resources.
