# Feasibility — what is actually proven

Verified 2026-09-01 against the live install at
`/mnt/ssd/Cyberpunk 2077/game/prefix/drive_c/game`. Nothing below is assumed.

## The toolchain round-trips losslessly

| Test | Command | Result |
|---|---|---|
| `.questphase` -> JSON -> `.questphase` | `WolvenKit.CLI convert serialize` / `deserialize` | **byte-identical**, md5 `701b871b98b78f1b6ebcbeced9b2e62e`, 16085 B |
| `.scene` -> JSON | `convert serialize` | 1.3 MB, no errors |
| `.journal` -> JSON | `convert serialize` | clean nested tree, see below |
| archive `extract` -> `pack` | `extract` / `pack` | file list identical |

Therefore quest resources can be **generated by script** and the engine gets a
structurally valid file. No GUI step is required.

CLI: `DOTNET_ROLL_FORWARD=LatestMajor dotnet /mnt/sata/WolvenKit/WolvenKit.CLI/bin/Release/net8.0/WolvenKit.CLI.dll`
The Linux build warns `Oodle couldn't be loaded, using Kraken.dll` — harmless for
quest/scene/journal (small buffers). Use the wine build at
`/mnt/sata/weapon_mod/wkcli_win/WolvenKit.CLI.exe` for final packing.

## Injection: ArchiveXL native quest phases

ArchiveXL **1.14.0** is installed and its DLL carries the `quest` / `phases` /
`parent` / `connection` keys. A `.xl` attaches a phase to the root graph with no
vanilla file override:

```yaml
quest:
  phases:
    - path: mod\ash_cache\quest\ash_cache.questphase
      parent: base\quest\cyberpunk2077.quest
    - path: mod\ash_cache\quest\ash_cache.questphase
      parent: ep1\quest\ep1_standalone.quest      # Phantom Liberty standalone
    - path: mod\ash_cache\quest\ash_cache.questphase
      parent: mod\quest\newgameplus.quest          # NG+ is installed here
    - path: mod\ash_cache\quest\ash_cache.questphase
      parent: mod\quest\newgameplus_q001.quest
    - path: mod\ash_cache\quest\ash_cache.questphase
      parent: mod\quest\newgameplus_standalone.quest
```

Confirmed in use by Undermine Quest Series (17186) and Aldecaldos High Stakes (18023).

The older **Deceptious Quest Core** slot system (DQC overrides vanilla
`base\quest\minor_quests\mq000\mq000.questphase` and exposes 40 numbered stubs) is
NOT used here — slots collide silently. Observed claims among the local downloads:
01 Hot Fuzz, 02 One More Light, 03 Californication, 07 Encore.

## The one genuinely hard part: `.scene`

One conversation in `hot_fuzz.scene` is 1.3 MB of JSON — 336 node ids, 185 output
sockets, 153 actor ids, 136 performers, 86 animation SRRefs, 92 actor-behavior
sections. Hand-authoring that is not realistic; it is a GUI-editor artifact.

Mitigation is a design decision, not a technical one. See `tech_spec.md`.

## Voice

Optional. Undermine ships subtitles only. Aldecaldos ships custom `.wem` under
`mod\localization\en-us\vo\` plus a `vomaps` block in its `.xl`.
`WolvenKit.CLI wwise` is **WEM->OGG only** — encoding *to* `.wem` needs an
external tool.

## ua-ua trap

The user plays Ukrainian. Hot Fuzz maps only `en-us` and its quest UI will render
blank for them. DQC and Aldecaldos alias all 19 locales to the en-us file. This mod
MUST include `ua-ua` — as a real translation, since it is the user's native language.
